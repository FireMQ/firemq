# Changelog

## 0.1.0

The first release: a synchronous Dart client for FireMQ over the C API of the Rust client.
It declares queues and exchanges, binds them, publishes with confirms, subscribes with a
prefetch, and acknowledges messages. See the
[FireMQ changelog](https://github.com/FireMQ/firemq/blob/main/CHANGELOG.md) for the broker.
